# digital-literacy-project
This repository holds a Digital Literacy Portfolio developed for the CSE0001 course of VIT Bhopal University. Being a Student Digital Ambassador, this project aims to develop key digital literacy skills for personal academic and professional development. The project includes five modules: developing an infographic, creating a digital portfolio, exploring coding and collaboration tools, writing professional emails along with etiquette tips, and exploring cybercrime and prevention strategies. Each of these activities is divided into a structured folder along with relevant files and reflections. The project reflects key online practices such as online etiquette, communication skills, and cybersecurity awareness while also providing a basic framework for creating a strong and professional online presence.
